## DSA PROBLEMS

### DP & String Problems

#### 1. Minimum String Appends for Subsequence
**Problem:** Given strings `s` and `t`, find minimum times to append `s` to make `t` a subsequence.

**Example:** `s = "boy"`, `t = "oyb"` → Answer: `2` ("boyboy")

**Approach:** Greedy + Two Pointers - cycle through `s`, increment count on cycle completion

**TC:** O(|s| × |t|) | **SC:** O(1)

```cpp
int minAppends(string s, string t) {
    int n = s.length(), m = t.length();
    int appends = 1, i = 0, j = 0;

    while (j < m) {
        int start_i = i;

        // Match as many chars as possible in current cycle
        while (i < n && j < m) {
            if (s[i] == t[j]) j++;
            i++;
        }

        // If no progress made, check if char exists in s
        if (start_i == 0 && i == n && j < m) {
            bool found = false;
            for (char c : s) {
                if (c == t[j]) { found = true; break; }
            }
            if (!found) return -1; // Impossible
        }

        // Reset and increment if needed
        if (i == n && j < m) {
            appends++;
            i = 0;
        }
    }
    return appends;
}
```

**Interview Tips:**
- Edge case: Characters in `t` not in `s` → return -1
- Optimization: Pre-compute next occurrence map
- Follow-up: Circular string variant

### Graph Problems

#### 2. Cheapest Flights Within K Stops (LeetCode 787)
**Problem:** Find cheapest flight price from source to destination with at most K stops.

**Approach:** Modified Dijkstra with state = (cost, node, stops)

**TC:** O(E × K × log(E × K)) | **SC:** O(N × K)

```cpp
int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
    vector<vector<pair<int, int>>> graph(n);
    for (auto& f : flights) {
        graph[f[0]].push_back({f[1], f[2]}); // {to, cost}
    }

    // {cost, node, stops}
    priority_queue<vector<int>, vector<vector<int>>, greater<>> pq;
    pq.push({0, src, 0});

    vector<vector<int>> dist(n, vector<int>(k + 2, INT_MAX));
    dist[src][0] = 0;

    while (!pq.empty()) {
        auto curr = pq.top(); pq.pop();
        int cost = curr[0], node = curr[1], stops = curr[2];

        if (node == dst) return cost;
        if (stops > k) continue;

        for (auto& [neighbor, price] : graph[node]) {
            int newCost = cost + price;
            if (newCost < dist[neighbor][stops + 1]) {
                dist[neighbor][stops + 1] = newCost;
                pq.push({newCost, neighbor, stops + 1});
            }
        }
    }
    return -1;
}
```

**Interview Tips:**
- State includes stops, not just distance
- Bellman-Ford alternative: O(K × E), simpler but slower
- Mention: "Standard Dijkstra won't work because we need to track stops"

#### 3. Grid Navigation with Directional Cost (0-1 BFS)
**Problem:** 2D grid with arrows (1=right, 2=left, 3=down, 4=up). Moving in arrow direction = cost 0, otherwise = cost 1. Find min cost (0,0) → (n-1, m-1).

**Approach:** 0-1 BFS using deque (cost-0 moves to front, cost-1 to back)

**TC:** O(n × m) | **SC:** O(n × m)

```cpp
int minCost(vector<vector<int>>& grid) {
    int n = grid.size(), m = grid[0].size();
    int dx[] = {0, 0, 0, 1, -1};
    int dy[] = {0, 1, -1, 0, 0};

    vector<vector<int>> cost(n, vector<int>(m, INT_MAX));
    deque<pair<int, int>> dq;

    dq.push_back({0, 0});
    cost[0][0] = 0;

    while (!dq.empty()) {
        auto [x, y] = dq.front(); dq.pop_front();

        for (int dir = 1; dir <= 4; dir++) {
            int nx = x + dx[dir], ny = y + dy[dir];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;

            int newCost = cost[x][y] + (grid[x][y] == dir ? 0 : 1);

            if (newCost < cost[nx][ny]) {
                cost[nx][ny] = newCost;
                if (grid[x][y] == dir) {
                    dq.push_front({nx, ny});
                } else {
                    dq.push_back({nx, ny});
                }
            }
        }
    }
    return cost[n-1][m-1];
}
```

**Interview Tips:**
- Why 0-1 BFS? Edge weights are binary
- Dijkstra works but overkill: O(nm log nm)
- Key insight: Deque maintains cost ordering naturally

#### 4. Course Schedule II (Topological Sort)
**Problem:** Return course order given prerequisites (directed graph).

**Approach:** Kahn's Algorithm (BFS-based topological sort)

**TC:** O(V + E) | **SC:** O(V + E)

```cpp
vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> graph(numCourses);
    vector<int> indegree(numCourses, 0);

    for (auto& p : prerequisites) {
        graph[p[1]].push_back(p[0]); // p[1] -> p[0]
        indegree[p[0]]++;
    }

    queue<int> q;
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) q.push(i);
    }

    vector<int> order;
    while (!q.empty()) {
        int course = q.front(); q.pop();
        order.push_back(course);

        for (int next : graph[course]) {
            if (--indegree[next] == 0) q.push(next);
        }
    }

    return order.size() == numCourses ? order : vector<int>{};
}
```

**Interview Tips:**
- DFS alternative exists but BFS is cleaner for this
- Cycle detection: if order.size() != numCourses
- Mention: "Kahn's algorithm for topological sort"

#### 5. Alien Dictionary
**Problem:** Given sorted words in alien language, derive character ordering.

**Approach:** Build graph from character ordering → Topological sort

**TC:** O(C) where C = total characters | **SC:** O(1) (26 letters max)

```cpp
string alienOrder(vector<string>& words) {
    unordered_map<char, unordered_set<char>> graph;
    unordered_map<char, int> indegree;

    // Initialize all characters
    for (string& word : words) {
        for (char c : word) {
            indegree[c] = 0;
        }
    }

    // Build graph
    for (int i = 0; i < words.size() - 1; i++) {
        string word1 = words[i], word2 = words[i + 1];
        int minLen = min(word1.length(), word2.length());

        // Edge case: "abc" before "ab" is invalid
        if (word1.length() > word2.length() &&
            word1.substr(0, minLen) == word2.substr(0, minLen)) {
            return "";
        }

        for (int j = 0; j < minLen; j++) {
            if (word1[j] != word2[j]) {
                if (graph[word1[j]].find(word2[j]) == graph[word1[j]].end()) {
                    graph[word1[j]].insert(word2[j]);
                    indegree[word2[j]]++;
                }
                break;
            }
        }
    }

    // Topological sort
    queue<char> q;
    for (auto& [c, deg] : indegree) {
        if (deg == 0) q.push(c);
    }

    string result;
    while (!q.empty()) {
        char c = q.front(); q.pop();
        result += c;

        for (char next : graph[c]) {
            if (--indegree[next] == 0) q.push(next);
        }
    }

    return result.length() == indegree.size() ? result : "";
}
```

**Interview Tips:**
- Edge case: longer word before shorter with same prefix → invalid
- Handle all edge cases: empty input, single char, cycles
- Mention: "Graph construction + topological sort pattern"

### Sliding Window

#### 6. Longest Subarray with Absolute Diff ≤ Limit (LeetCode 1438)
**Problem:** Find longest subarray where abs(max - min) ≤ limit.

**Approach:** Sliding window + Two monotonic deques (one for max, one for min)

**TC:** O(n) | **SC:** O(n)

```cpp
int longestSubarray(vector<int>& nums, int limit) {
    deque<int> maxDeque; // decreasing order
    deque<int> minDeque; // increasing order
    int left = 0, maxLen = 0;

    for (int right = 0; right < nums.size(); right++) {
        // Maintain maxDeque in decreasing order
        while (!maxDeque.empty() && nums[maxDeque.back()] <= nums[right]) {
            maxDeque.pop_back();
        }
        maxDeque.push_back(right);

        // Maintain minDeque in increasing order
        while (!minDeque.empty() && nums[minDeque.back()] >= nums[right]) {
            minDeque.pop_back();
        }
        minDeque.push_back(right);

        // Shrink window if diff > limit
        while (nums[maxDeque.front()] - nums[minDeque.front()] > limit) {
            left++;
            if (maxDeque.front() < left) maxDeque.pop_front();
            if (minDeque.front() < left) minDeque.pop_front();
        }

        maxLen = max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

**Interview Tips:**
- Why deques? Need O(1) access to both ends
- Invariant: Front of maxDeque = max, front of minDeque = min
- Alternative: Multiset O(n log n), but deque is optimal

#### 7. Maximum Points from Cards (LeetCode 1423)
**Problem:** Take `k` cards from either end of array, maximize sum.

**Approach:** Max from ends = Total sum - Min sum of middle (n-k) window

**TC:** O(n) | **SC:** O(1)

```cpp
int maxScore(vector<int>& cardPoints, int k) {
    int n = cardPoints.size();
    int totalSum = 0;
    for (int x : cardPoints) totalSum += x;

    if (k == n) return totalSum;

    // Find minimum sum subarray of length (n - k)
    int windowSize = n - k;
    int windowSum = 0;

    for (int i = 0; i < windowSize; i++) {
        windowSum += cardPoints[i];
    }

    int minWindowSum = windowSum;
    for (int i = windowSize; i < n; i++) {
        windowSum += cardPoints[i] - cardPoints[i - windowSize];
        minWindowSum = min(minWindowSum, windowSum);
    }

    return totalSum - minWindowSum;
}
```

**Interview Tips:**
- Key insight: Transform to "find min middle window"
- Alternative: Prefix sums with all combinations (slower)
- Edge case: k == n

### Array Problems

#### 8. Bus Routes (BFS on Graph of Routes)
**Problem:** Find minimum buses to reach target stop from source.

**Approach:** Build graph where nodes = bus routes, BFS to find shortest path

**TC:** O(N × R) where N = stops, R = routes | **SC:** O(N × R)

```cpp
int numBusesToDestination(vector<vector<int>>& routes, int source, int target) {
    if (source == target) return 0;

    // Map: stop -> list of routes
    unordered_map<int, vector<int>> stopToRoutes;
    for (int i = 0; i < routes.size(); i++) {
        for (int stop : routes[i]) {
            stopToRoutes[stop].push_back(i);
        }
    }

    queue<int> q;
    unordered_set<int> visitedRoutes;
    unordered_set<int> visitedStops;

    for (int route : stopToRoutes[source]) {
        q.push(route);
        visitedRoutes.insert(route);
    }

    int buses = 1;
    while (!q.empty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            int route = q.front(); q.pop();

            for (int stop : routes[route]) {
                if (stop == target) return buses;
                if (visitedStops.count(stop)) continue;
                visitedStops.insert(stop);

                for (int nextRoute : stopToRoutes[stop]) {
                    if (!visitedRoutes.count(nextRoute)) {
                        visitedRoutes.insert(nextRoute);
                        q.push(nextRoute);
                    }
                }
            }
        }
        buses++;
    }
    return -1;
}
```

**Interview Tips:**
- Key: BFS on routes (not stops) to count buses
- Two visited sets: routes and stops
- Mention: "Transform stop-to-stop into route-to-route graph"

### Disjoint Set Union

#### 9. Shared Cab Problem (DSU)
**Problem:**
- V1: Count running cabs at each log timestamp
- V2: Find timestamp when all users in one cab

**Logs Format:** `(userA, userB, timestamp)` - userA and userB share a cab

**Approach:** DSU with path compression + union by rank

**TC:** O(α(n)) per operation ≈ O(1) | **SC:** O(n)

```cpp
class DSU {
private:
    vector<int> parent, rank, size;
    int numComponents;

public:
    DSU(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        size.resize(n, 1);
        numComponents = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    // Find with path compression
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // Union by rank
    bool unite(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return false;

        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
            size[rootY] += size[rootX];
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
            size[rootX] += size[rootY];
        } else {
            parent[rootY] = rootX;
            size[rootX] += size[rootY];
            rank[rootX]++;
        }
        numComponents--;
        return true;
    }

    int getNumComponents() { return numComponents; }
    int getComponentSize(int x) { return size[find(x)]; }
};

// Version 1: Count cabs at each log
vector<int> countCabsAtEachLog(vector<tuple<int, int, int>>& logs) {
    map<int, int> userToId;
    int userId = 0;

    for (auto& [a, b, t] : logs) {
        if (!userToId.count(a)) userToId[a] = userId++;
        if (!userToId.count(b)) userToId[b] = userId++;
    }

    DSU dsu(userId);
    vector<int> result;

    for (auto& [a, b, t] : logs) {
        dsu.unite(userToId[a], userToId[b]);
        result.push_back(dsu.getNumComponents());
    }
    return result;
}

// Version 2: Find timestamp when all in one cab
int findTimestampForOneCab(vector<tuple<int, int, int>>& logs) {
    map<int, int> userToId;
    int userId = 0;

    for (auto& [a, b, t] : logs) {
        if (!userToId.count(a)) userToId[a] = userId++;
        if (!userToId.count(b)) userToId[b] = userId++;
    }

    DSU dsu(userId);
    for (auto& [a, b, t] : logs) {
        dsu.unite(userToId[a], userToId[b]);
        if (dsu.getNumComponents() == 1) return t;
    }
    return -1;
}
```

**Interview Tips:**
- Path compression: Flattens tree during find
- Union by rank: Keeps tree shallow
- Alternative: Union by size (attach smaller to larger)
- α(n) = inverse Ackermann function (practically constant)

### Linked List

#### 10. Reverse Linked List Every K Nodes
**Problem:** Reverse every `k` nodes. If remaining < `k`, leave unchanged.

**Example:** `A->B->C->D->E`, k=2 → `B->A->D->C->E`

**Approach:** Recursive reversal with count check

**TC:** O(n) | **SC:** O(n/k) recursion stack

```cpp
ListNode* reverseKGroup(ListNode* head, int k) {
    // Count nodes
    int count = 0;
    ListNode* curr = head;
    while (curr && count < k) {
        curr = curr->next;
        count++;
    }

    if (count < k) return head; // Less than k nodes left

    // Reverse k nodes
    ListNode* prev = nullptr;
    curr = head;
    for (int i = 0; i < k; i++) {
        ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }

    // Recurse for remaining
    head->next = reverseKGroup(curr, k);
    return prev;
}
```

**Interview Tips:**
- Key: Check count first before reversing
- Alternative: Iterative with stack
- Edge case: k > list length

### Mathematical

#### 11. Next Greater Palindrome
**Problem:** Find next palindrome greater than given number.

**Approach:** Mirror & Carry Propagation

**TC:** O(n) where n = digits | **SC:** O(n)

```cpp
string nextPalindrome(string num) {
    int n = num.length();
    vector<int> digits;
    for (char c : num) digits.push_back(c - '0');

    // Special case: all 9s → 100...001
    bool allNines = true;
    for (int d : digits) {
        if (d != 9) { allNines = false; break; }
    }
    if (allNines) return "1" + string(n, '0') + "1";

    // Mirror left to right
    int mid = n / 2;
    bool leftSmaller = false;

    for (int i = 0; i < mid; i++) {
        if (digits[i] < digits[n - 1 - i]) {
            leftSmaller = true;
            break;
        } else if (digits[i] > digits[n - 1 - i]) {
            break;
        }
    }

    // Mirror
    for (int i = 0; i < mid; i++) {
        digits[n - 1 - i] = digits[i];
    }

    // If mirrored <= original, increment middle
    string mirrored;
    for (int d : digits) mirrored += to_string(d);

    if (leftSmaller || num == mirrored) {
        int carry = 1;

        if (n % 2 == 1) {
            digits[mid] += carry;
            carry = digits[mid] / 10;
            digits[mid] %= 10;
        }

        int left = mid - 1;
        int right = (n % 2 == 0) ? mid : mid + 1;

        while (left >= 0 && carry) {
            digits[left] += carry;
            carry = digits[left] / 10;
            digits[left] %= 10;
            digits[right] = digits[left];
            left--;
            right++;
        }
    }

    string result;
    for (int d : digits) result += to_string(d);
    return result;
}
```

**Interview Tips:**
- Pattern: Mirror → Check → Increment → Propagate carry
- Edge cases: All 9s, single digit
- Must ensure result > original

### 3. Expiry Counter (Machine Coding)

**Requirements:**
- `putElement(key)` - Add element with current timestamp
- `getElementCount(key)` - Count non-expired elements for key
- `getTotalElements()` - Count all non-expired elements

- **Facade Pattern** - Simple interface over complex timestamp management

```java
class ExpiryCounter {
```

- Background cleanup thread (production)
- Use TreeMap for auto-sorted timestamps
- Consider LRU eviction for memory limits

**Alternative Approach:**
- Priority Queue + HashMap (slower reads)

## QUICK REFERENCE

### Time Complexity Cheat Sheet
| Operation | Best Case | Average | Worst | Notes |
|-----------|-----------|---------|-------|-------|
| DSU Find | O(1) | O(α(n)) | O(log n) | With path compression |
| DSU Union | O(1) | O(α(n)) | O(log n) | With union by rank |
| Topological Sort | - | O(V + E) | O(V + E) | DFS or BFS |
| 0-1 BFS | - | O(V + E) | O(V + E) | Deque-based |
| Dijkstra | - | O(E log V) | O(E log V) | Priority queue |
| Sliding Window | - | O(n) | O(n) | Amortized |

### Common Patterns

**Graph Problems:**
1. Topological Sort → Course Schedule, Alien Dictionary
2. 0-1 BFS → Grid with binary edge weights
3. Modified Dijkstra → K stops, multiple constraints

**Sliding Window:**
1. Fixed size → Max/Min in window
2. Variable size → Condition-based shrink/expand
3. Monotonic Deque → Track max/min efficiently

**DSU:**
1. Connected Components → Union users, cabs
2. Cycle Detection → Union with conflict check
3. Online Queries → Dynamic connectivity

### Interview Communication Tips

**Before Coding:**
1. Restate problem in your own words
2. Ask clarifying questions
3. Discuss 2-3 approaches (brute → optimal)
4. State TC/SC for each approach
5. Get agreement on approach

**While Coding:**
1. Think aloud
2. Explain variable names
3. Handle edge cases explicitly
4. Write clean, readable code

**After Coding:**
1. Dry run with example
2. Discuss optimizations
3. Mention trade-offs
4. Handle follow-up questions

### LLD Communication Tips

**Requirements Phase:**
1. Ask: Functional requirements
2. Ask: Non-functional (scale, performance)
3. Ask: Constraints, assumptions
4. Clarify: What's in/out of scope

**Design Phase:**
1. Start with core entities
2. Identify relationships
3. Choose design patterns (explain why)
4. Discuss extensibility
5. Handle edge cases

**Code Phase:**
1. Write interface/abstract classes first
2. Implement incrementally
3. Explain design decisions
4. Keep code runnable
5. Test as you go

### Common Mistakes to Avoid

**DSA:**
- ❌ Jumping to code without explaining
- ❌ Not stating TC/SC upfront
- ❌ Missing edge cases (empty, single element, duplicates)
- ❌ Not testing code with example
- ❌ Writing unreadable variable names

**LLD:**
- ❌ Not asking clarifying questions
- ❌ Jumping to implementation without design
- ❌ Not explaining design pattern choices
- ❌ Writing non-extensible code
- ❌ Ignoring production concerns (concurrency, errors)
