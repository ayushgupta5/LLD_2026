HLD:-
Design Ride Sharing Application HLD:-
#Functional Requirements:-
1. User can do Registration (Auth SVC) (User SVC)
2. Book a Ride (src + dst) (Create a Ride) (Ride SVC)
2.1 Join a Ride by Passenger (Matching Service) (Driver <--> Passenger)
3. Real Time Driver Location (Location SVC)
4. Fare Calculation (Pricing SVC)
5. Payment (Payment SVC))
6. Notification (Notification SVC)
7. Ride History

#Non Functional Requirement:-
1. High Available 99.99%
2. Latency should be Less
3. Scalable
4. Consistency (Payment)
5. Security


client --> LB --> API gw --> Ingestion Service --> Queue-->Core SVC--> DB
