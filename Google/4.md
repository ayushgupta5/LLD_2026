## Question 1: Sum of Good Arithmetic Sequences

**Difficulty:** Medium

### Problem Statement
A good arithmetic sequence has a common difference of either 1 or -1. Given an integer array, return the sum of the sums of each subarray that is a good arithmetic sequence.

Single-element subarrays are always good arithmetic sequences.

### Example
```
Input: nums = [7, 4, 5, 6, 5]
Output: 73

Explanation:
Good sequences:
[7], [4], [5], [6], [5] → sums: 7, 4, 5, 6, 5
[4,5], [5,6], [6,5] → sums: 9, 11, 11
[4,5,6] → sum: 15

Total: 7 + 4 + 5 + 6 + 5 + 9 + 11 + 11 + 15 = 73
```

### C++ Solution
```cpp
class Solution {
public:
    long long sumOfGoodSequences(vector<int>& nums) {
        int n = nums.size();
        long long totalSum = 0;

        // All single elements contribute
        for (int num : nums) {
            totalSum += num;
        }

        // Check all subarrays of length >= 2
        for (int i = 0; i < n; i++) {
            long long currentSum = nums[i];
            int commonDiff = 0;
            bool isFirst = true;

            for (int j = i + 1; j < n; j++) {
                int diff = nums[j] - nums[j-1];

                if (isFirst) {
                    // First pair - check if diff is 1 or -1
                    if (diff != 1 && diff != -1) break;
                    commonDiff = diff;
                    isFirst = false;
                    currentSum += nums[j];
                    totalSum += currentSum;
                } else {
                    // Check if common difference maintained
                    if (diff == commonDiff) {
                        currentSum += nums[j];
                        totalSum += currentSum;
                    } else {
                        break;
                    }
                }
            }
        }

        return totalSum;
    }
};
```

**Time Complexity:** O(N²)
**Space Complexity:** O(1)

## Question 2: Linux Directory Path Composition

**Difficulty:** Hard

### Problem Statement
Given a list of file paths, return the composed list showing directories containing multiple files together, and individual file paths for single files.

A directory should be shown if it contains files directly (not in subdirectories).

### Example
```
Input:
/home/foo/bar/file1.txt
/home/foo/bar/file2.txt
/home/foo/mobi/wiki/file3.txt
/home/foo/mobi/file4.txt
/home/foo/file5.txt
/home/foo/mobi/file6.txt

Output:
/home/foo/bar → (file1.txt, file2.txt)
/home/foo/mobi/wiki/file3.txt → (file3.txt)
/home/foo/mobi → (file4.txt, file6.txt)
/home/foo/file5.txt → (file5.txt)
```

### C++ Solution
```cpp
struct TrieNode {
    map<string, TrieNode*> children;
    vector<string> files;
    bool hasSubdirs = false;
};

class Solution {
public:
    vector<string> composePaths(vector<string>& paths) {
        TrieNode* root = new TrieNode();

        // Build trie
        for (const string& path : paths) {
            insertPath(root, path);
        }

        // Collect composed paths
        vector<string> result;
        collectPaths(root, "", result);

        return result;
    }

private:
    void insertPath(TrieNode* root, const string& path) {
        vector<string> parts = split(path, '/');
        TrieNode* curr = root;

        // Navigate to parent directory
        for (int i = 1; i < parts.size() - 1; i++) {
            if (!curr->children.count(parts[i])) {
                curr->children[parts[i]] = new TrieNode();
            }
            curr->hasSubdirs = true;
            curr = curr->children[parts[i]];
        }

        // Add file to current directory
        curr->files.push_back(parts.back());
    }

    void collectPaths(TrieNode* node, string currentPath, vector<string>& result) {
        // If node has files and subdirectories, or multiple files
        if (!node->files.empty()) {
            if (node->files.size() > 1 || !node->hasSubdirs) {
                // Compose directory
                string output = currentPath.empty() ? "/" : currentPath;
                output += " → (";
                for (int i = 0; i < node->files.size(); i++) {
                    if (i > 0) output += ", ";
                    output += node->files[i];
                }
                output += ")";
                result.push_back(output);
            } else {
                // Single file with subdirs - show full path
                string fullPath = currentPath + "/" + node->files[0];
                result.push_back(fullPath + " → (" + node->files[0] + ")");
            }
        }

        // Process subdirectories
        for (auto& [dir, child] : node->children) {
            collectPaths(child, currentPath + "/" + dir, result);
        }
    }

    vector<string> split(const string& s, char delimiter) {
        vector<string> tokens;
        string token;
        istringstream tokenStream(s);
        while (getline(tokenStream, token, delimiter)) {
            if (!token.empty()) {
                tokens.push_back(token);
            }
        }
        return tokens;
    }
};
```

**Time Complexity:** O(N × L) where N is paths, L is avg path length
**Space Complexity:** O(N × L)

## Question 3: Extreme Sum of All Subarrays

**Difficulty:** Hard

### Problem Statement
For each subarray, the extreme sum is the maximum element + minimum element. Return the sum of extreme sums for all subarrays.

### Example
```
Input: arr = [12, 15, 16, 81, 23, 19, 21, 43]
Output: ?

Explanation:
Subarray [12]: max=12, min=12, extreme=24
Subarray [12,15]: max=15, min=12, extreme=27
Subarray [12,15,16]: max=16, min=12, extreme=28
... and so on for all subarrays
```

### C++ Solution
```cpp
class Solution {
public:
    long long extremeSum(vector<int>& arr) {
        int n = arr.size();
        long long totalSum = 0;

        // For each starting position
        for (int i = 0; i < n; i++) {
            int minVal = arr[i];
            int maxVal = arr[i];

            // Extend ending position
            for (int j = i; j < n; j++) {
                minVal = min(minVal, arr[j]);
                maxVal = max(maxVal, arr[j]);
                totalSum += (minVal + maxVal);
            }
        }

        return totalSum;
    }

    // Optimized O(n) solution using contribution technique
    long long extremeSumOptimized(vector<int>& arr) {
        int n = arr.size();
        long long result = 0;

        // Contribution of each element as maximum
        result += contributionAsMax(arr);

        // Contribution of each element as minimum
        result += contributionAsMin(arr);

        return result;
    }

private:
    long long contributionAsMax(vector<int>& arr) {
        int n = arr.size();
        long long contribution = 0;
        stack<int> st;

        for (int i = 0; i < n; i++) {
            while (!st.empty() && arr[st.top()] < arr[i]) {
                st.pop();
            }

            int left = st.empty() ? -1 : st.top();

            // Find next greater to right
            int right = n;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] > arr[i]) {
                    right = j;
                    break;
                }
            }

            // arr[i] is max in (i - left) * (right - i) subarrays
            long long count = (long long)(i - left) * (right - i);
            contribution += count * arr[i];

            st.push(i);
        }

        return contribution;
    }

    long long contributionAsMin(vector<int>& arr) {
        int n = arr.size();
        long long contribution = 0;
        stack<int> st;

        for (int i = 0; i < n; i++) {
            while (!st.empty() && arr[st.top()] > arr[i]) {
                st.pop();
            }

            int left = st.empty() ? -1 : st.top();

            // Find next smaller to right
            int right = n;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[i]) {
                    right = j;
                    break;
                }
            }

            long long count = (long long)(i - left) * (right - i);
            contribution += count * arr[i];

            st.push(i);
        }

        return contribution;
    }
};
```

**Time Complexity:** O(N²) brute force, O(N) optimized
**Space Complexity:** O(1) brute force, O(N) optimized

## Question 4: Loose Median from Data Stream

**Difficulty:** Hard

### Problem Statement
Find median from data stream, but with a "loose" definition: the median can be any number in the range between two nearest powers of 2 from the actual median.

Expected: O(1) time and O(1) space.

### Example
```
Input: stream = [1, 2, 3, 5, 6, 7, 8]
Actual median: 5
Nearest powers of 2: 4 (2²) and 8 (2³)
Loose median: any number in range [4, 8]
```

### C++ Solution
```cpp
class LooseMedianFinder {
private:
    // Buckets for ranges [0-1], [2-3], [4-7], [8-15], [16-31], ...
    unordered_map<int, int> buckets; // bucket_id -> count
    int totalCount = 0;

    int getBucketId(int num) {
        if (num <= 1) return 0;
        // Find which power of 2 range
        int power = 0;
        int temp = num;
        while (temp > 1) {
            temp >>= 1;
            power++;
        }
        return power;
    }

    pair<int, int> getBucketRange(int bucketId) {
        if (bucketId == 0) return {0, 1};
        int start = 1 << bucketId;
        int end = (1 << (bucketId + 1)) - 1;
        return {start, end};
    }

public:
    void addNum(int num) {
        int bucketId = getBucketId(num);
        buckets[bucketId]++;
        totalCount++;
    }

    int findLooseMedian() {
        int target = (totalCount + 1) / 2;
        int cumulative = 0;

        // Find bucket containing median
        for (int i = 0; i <= 30; i++) {
            if (!buckets.count(i)) continue;

            cumulative += buckets[i];
            if (cumulative >= target) {
                // Median is in bucket i
                auto [start, end] = getBucketRange(i);
                return (start + end) / 2; // Return mid of range
            }
        }

        return 0;
    }
};
```

**Time Complexity:** O(1) for both operations
**Space Complexity:** O(log MaxValue) for buckets

## Question 5: Summary Ranges with Gap K

**Difficulty:** Medium

### Problem Statement
Similar to Summary Ranges but club integers with a difference of at most K.

### Example
```
Input: arr = [1, 3, 6], K = 3
Output: [[1, 6]]
Explanation: 1 and 3 differ by 2 (≤3), 3 and 6 differ by 3 (≤3)

Input: arr = [0, 2, 3, 4, 6, 8, 9], K = 2
Output: [[0, 4], [6, 9]]
```

### C++ Solution
```cpp
class Solution {
public:
    vector<vector<int>> summaryRangesWithGap(vector<int>& nums, int k) {
        vector<vector<int>> result;
        if (nums.empty()) return result;

        int start = nums[0];
        int end = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] - end <= k) {
                // Extend current range
                end = nums[i];
            } else {
                // Save current range and start new one
                result.push_back({start, end});
                start = nums[i];
                end = nums[i];
            }
        }

        // Add last range
        result.push_back({start, end});

        return result;
    }

    // Alternative: return as strings
    vector<string> summaryRangesString(vector<int>& nums, int k) {
        vector<string> result;
        if (nums.empty()) return result;

        int start = nums[0];
        int end = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] - end <= k) {
                end = nums[i];
            } else {
                if (start == end) {
                    result.push_back(to_string(start));
                } else {
                    result.push_back(to_string(start) + "->" + to_string(end));
                }
                start = nums[i];
                end = nums[i];
            }
        }

        // Add last range
        if (start == end) {
            result.push_back(to_string(start));
        } else {
            result.push_back(to_string(start) + "->" + to_string(end));
        }

        return result;
    }
};
```

**Time Complexity:** O(N)
**Space Complexity:** O(1) excluding output

## Question 6: Maximum Frequency String After String

**Difficulty:** Medium

### Problem Statement
Given a 2D array of strings, find the maximum frequency string that occurs next to a given string.

### Example
```
Input: data = [["cat", "dog"], ["dog", "cat"], ["dog", "bird"], ["cat", "mouse"]]
Query: "dog"
Output: "cat" (appears after "dog" 2 times)
```

### C++ Solution
```cpp
class Solution {
public:
    string maxFrequencyNext(vector<vector<string>>& data, string query) {
        // Map: string -> (next_string -> frequency)
        unordered_map<string, unordered_map<string, int>> nextFreq;

        // Build the map
        for (const auto& pair : data) {
            if (pair.size() >= 2) {
                nextFreq[pair[0]][pair[1]]++;
            }
        }

        // Find max frequency for query string
        if (!nextFreq.count(query)) return "";

        string maxString = "";
        int maxCount = 0;

        for (const auto& [next, count] : nextFreq[query]) {
            if (count > maxCount) {
                maxCount = count;
                maxString = next;
            }
        }

        return maxString;
    }

    // Optimized version with trie for prefix matching
    unordered_map<string, map<string, int>> buildFrequencyMap(
        vector<vector<string>>& sequences) {
        unordered_map<string, map<string, int>> freqMap;

        for (const auto& seq : sequences) {
            for (int i = 0; i < seq.size() - 1; i++) {
                freqMap[seq[i]][seq[i + 1]]++;
            }
        }

        return freqMap;
    }
};
```

**Time Complexity:** O(N) for building map, O(K) for query where K is unique next strings
**Space Complexity:** O(N × M) where M is avg unique next strings

## Question 7: Extended Isomorphic Strings

**Difficulty:** Medium

### Problem Statement
Check if two strings of unequal lengths are isomorphic. If yes, extend the shorter to match the longer.

### Example
```
Input: s1 = "abc", s2 = "dedef"
Output: true, extended = "abcbc"
Explanation: Pattern maps a->d, b->e, c->f

Input: s1 = "ab", s2 = "cdef"
Output: false
```

### C++ Solution
```cpp
class Solution {
public:
    pair<bool, string> extendIsomorphic(string shorter, string longer) {
        if (longer.length() % shorter.length() != 0) {
            // Check if pattern can extend
            if (!canExtend(shorter, longer)) {
                return {false, ""};
            }
        }

        unordered_map<char, char> mapStoL;
        unordered_map<char, char> mapLtoS;

        // Build mapping from one cycle
        int cycleLen = shorter.length();
        for (int i = 0; i < cycleLen; i++) {
            char s = shorter[i];
            char l = longer[i];

            if (mapStoL.count(s)) {
                if (mapStoL[s] != l) return {false, ""};
            } else {
                mapStoL[s] = l;
            }

            if (mapLtoS.count(l)) {
                if (mapLtoS[l] != s) return {false, ""};
            } else {
                mapLtoS[l] = s;
            }
        }

        // Verify the pattern holds for entire longer string
        for (int i = 0; i < longer.length(); i++) {
            char s = shorter[i % cycleLen];
            char l = longer[i];

            if (mapStoL[s] != l) {
                return {false, ""};
            }
        }

        // Extend shorter to match longer
        string extended = "";
        for (int i = 0; i < longer.length(); i++) {
            extended += shorter[i % cycleLen];
        }

        return {true, extended};
    }

private:
    bool canExtend(const string& shorter, const string& longer) {
        int s = 0, l = 0;
        unordered_map<char, char> mapStoL;
        unordered_map<char, char> mapLtoS;

        while (l < longer.length()) {
            char sChar = shorter[s % shorter.length()];
            char lChar = longer[l];

            if (mapStoL.count(sChar)) {
                if (mapStoL[sChar] != lChar) return false;
            } else {
                if (mapLtoS.count(lChar)) return false;
                mapStoL[sChar] = lChar;
                mapLtoS[lChar] = sChar;
            }

            s++;
            l++;
        }

        return true;
    }
};
```

**Time Complexity:** O(N) where N is length of longer string
**Space Complexity:** O(K) where K is unique characters

## Question 8: Array Division Equal Sum with Element Change

**Difficulty:** Medium

### Problem Statement
Find if an array can be divided into two subarrays of equal sum if you can change any one element to any value.

### Example
```
Input: arr = [1, 3, 4, 8]
Output: true
Explanation: Change 8 to 0 → [1,3,4,0], split as [1,3] and [4,0], both sum to 4

Input: arr = [1, 2, 3]
Output: true
```

### C++ Solution
```cpp
class Solution {
public:
    bool canDivideWithChange(vector<int>& arr) {
        int n = arr.size();
        if (n < 2) return false;

        int totalSum = accumulate(arr.begin(), arr.end(), 0);

        // Try changing each element
        for (int i = 0; i < n; i++) {
            // Try all split positions
            for (int split = 0; split < n; split++) {
                // Calculate what value arr[i] should be
                int leftSum = 0;
                for (int j = 0; j <= split; j++) {
                    if (j != i) leftSum += arr[j];
                }

                int rightSum = 0;
                for (int j = split + 1; j < n; j++) {
                    if (j != i) rightSum += arr[j];
                }

                // If i is on left, we need: leftSum + x = rightSum
                if (i <= split) {
                    int needed = rightSum - leftSum;
                    if (needed >= 0) return true;
                } else {
                    // If i is on right, we need: leftSum = rightSum + x
                    int needed = leftSum - rightSum;
                    if (needed >= 0) return true;
                }
            }
        }

        return false;
    }

    // Optimized O(n) solution
    bool canDivideWithChangeOptimized(vector<int>& arr) {
        int n = arr.size();
        vector<int> prefixSum(n + 1, 0);

        for (int i = 0; i < n; i++) {
            prefixSum[i + 1] = prefixSum[i] + arr[i];
        }

        int totalSum = prefixSum[n];

        // For each position i that we might change
        for (int changePos = 0; changePos < n; changePos++) {
            // For each split position
            for (int split = 0; split < n - 1; split++) {
                int leftSum = prefixSum[split + 1];
                int rightSum = totalSum - leftSum;

                if (changePos <= split) {
                    // Changing element on left
                    leftSum -= arr[changePos];
                    // Need: leftSum + x = rightSum
                    // x = rightSum - leftSum
                    if (rightSum >= leftSum) return true;
                } else {
                    // Changing element on right
                    rightSum -= arr[changePos];
                    // Need: leftSum = rightSum + x
                    // x = leftSum - rightSum
                    if (leftSum >= rightSum) return true;
                }
            }
        }

        return false;
    }
};
```

**Time Complexity:** O(N²)
**Space Complexity:** O(N)

## Question 9: Count Islands in Tree (0s and 1s)

**Difficulty:** Medium

### Problem Statement
Given a tree with nodes having values 0 or 1, count the number of islands (connected components of 1s).

### Example
```
Input: Tree where 1 means land, 0 means water
       1
      / \
     1   0
    / \   \
   1   0   1

Output: 2
Explanation: One island {1,1,1} on left, one island {1} on right
```

### C++ Solution
```cpp
struct TreeNode {
    int value;
    vector<TreeNode*> children;

    TreeNode(int v) : value(v) {}
};

class Solution {
public:
    int countIslands(TreeNode* root) {
        if (!root) return 0;

        int islands = 0;
        unordered_set<TreeNode*> visited;

        function<void(TreeNode*)> traverse = [&](TreeNode* node) {
            if (!node || visited.count(node)) return;

            if (node->value == 1 && !visited.count(node)) {
                // Found new island, do DFS to mark all connected 1s
                dfs(node, visited);
                islands++;
            }

            for (TreeNode* child : node->children) {
                traverse(child);
            }
        };

        traverse(root);
        return islands;
    }

private:
    void dfs(TreeNode* node, unordered_set<TreeNode*>& visited) {
        if (!node || visited.count(node) || node->value == 0) {
            return;
        }

        visited.insert(node);

        for (TreeNode* child : node->children) {
            dfs(child, visited);
        }
    }

    // O(1) space solution - modify tree (mark visited nodes)
    int countIslandsConstantSpace(TreeNode* root) {
        if (!root) return 0;

        int islands = 0;

        function<void(TreeNode*)> markIsland = [&](TreeNode* node) {
            if (!node || node->value != 1) return;

            node->value = -1; // Mark as visited

            for (TreeNode* child : node->children) {
                markIsland(child);
            }
        };

        function<void(TreeNode*)> traverse = [&](TreeNode* node) {
            if (!node) return;

            if (node->value == 1) {
                markIsland(node);
                islands++;
            }

            for (TreeNode* child : node->children) {
                traverse(child);
            }
        };

        traverse(root);

        // Restore tree (optional)
        function<void(TreeNode*)> restore = [&](TreeNode* node) {
            if (!node) return;
            if (node->value == -1) node->value = 1;
            for (TreeNode* child : node->children) {
                restore(child);
            }
        };
        restore(root);

        return islands;
    }
};
```

**Time Complexity:** O(N)
**Space Complexity:** O(N) with visited set, O(1) with modification

## Question 10: Maximum Sum Subarray with Same Start-End Values

**Difficulty:** Medium

### Problem Statement
Find the maximum sum of a subarray where the first and last elements are the same value.

**Follow-ups:**
1. Array contains negative numbers
2. Start and end values can be different
3. O(1) space complexity

### Example
```
Input: arr = [2, -1, 3, 2, 5]
Output: 11
Explanation: Subarray [2, -1, 3, 2, 5] has same start/end value 2, sum = 11

Input: arr = [1, 2, 3, 4, 1]
Output: 11
Explanation: Subarray [1, 2, 3, 4, 1], sum = 11
```

### C++ Solution
```cpp
class Solution {
public:
    int maxSumSameEnds(vector<int>& arr) {
        int n = arr.size();
        unordered_map<int, vector<int>> positions;

        // Store all positions of each value
        for (int i = 0; i < n; i++) {
            positions[arr[i]].push_back(i);
        }

        int maxSum = INT_MIN;

        // For each value that appears at least twice
        for (auto& [val, pos] : positions) {
            if (pos.size() >= 2) {
                // Calculate prefix sums for efficiency
                int left = pos[0];
                int right = pos.back();

                int sum = 0;
                for (int i = left; i <= right; i++) {
                    sum += arr[i];
                }
                maxSum = max(maxSum, sum);

                // Also check other pairs of same value
                for (int i = 0; i < pos.size(); i++) {
                    for (int j = i + 1; j < pos.size(); j++) {
                        int currSum = 0;
                        for (int k = pos[i]; k <= pos[j]; k++) {
                            currSum += arr[k];
                        }
                        maxSum = max(maxSum, currSum);
                    }
                }
            } else {
                // Single element
                maxSum = max(maxSum, val);
            }
        }

        return maxSum;
    }

    // Optimized with prefix sums
    int maxSumSameEndsOptimized(vector<int>& arr) {
        int n = arr.size();
        vector<int> prefixSum(n + 1, 0);

        for (int i = 0; i < n; i++) {
            prefixSum[i + 1] = prefixSum[i] + arr[i];
        }

        unordered_map<int, vector<int>> positions;
        for (int i = 0; i < n; i++) {
            positions[arr[i]].push_back(i);
        }

        int maxSum = INT_MIN;

        for (auto& [val, pos] : positions) {
            if (pos.size() == 1) {
                maxSum = max(maxSum, val);
            } else {
                // Check all pairs
                for (int i = 0; i < pos.size(); i++) {
                    for (int j = i; j < pos.size(); j++) {
                        int sum = prefixSum[pos[j] + 1] - prefixSum[pos[i]];
                        maxSum = max(maxSum, sum);
                    }
                }
            }
        }

        return maxSum;
    }
};
```

**Time Complexity:** O(N²) worst case
**Space Complexity:** O(N)

## Critical Interview Insights from Experiences

### What Causes Rejections:
- ❌ **Needing hints** - Even if you solve it, needing interviewer help can lead to No Hire
- ❌ **Small implementation mistakes** - Missing base cases can be heavily penalized
- ❌ **Time management** - Not completing all expected questions
- ❌ **Poor explanation** - Unable to prove time complexity mathematically
- ❌ **Misunderstanding problem** - Always clarify before coding

### Success Strategies:
- ✅ **Modular code** - Break into well-named functions
- ✅ **Ask for dry runs** - If problem unclear, request examples
- ✅ **Start simple** - Brute force first, then optimize
- ✅ **Verify base cases** - Don't assume, always check
- ✅ **Practice proofs** - Be able to prove complexity claims

### Feedback Patterns:
- **"Strong Hire"** requires: optimal solution + clean code + good communication
- **"Hire"** requires: working solution + reasonable approach
- **"Lean Hire"** means: solved but with issues (time, hints, or incomplete)
- **"No Hire"** results from: wrong solution, too many hints, or poor fundamentals

### Time Distribution (45-min rounds):
- 5 min: Problem understanding & clarification
- 5-10 min: Approach discussion
- 20-25 min: Implementation
- 5-10 min: Testing & complexity analysis
- Remaining: Follow-ups (critical!)
