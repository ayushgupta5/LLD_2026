## Question 1: Highest Straight Flush in Card Deck

**Difficulty:** Medium

### Problem Statement
Given a deck of cards with X suits and Y ranks, find the highest five-card straight flush (five cards of the same suit with consecutive ranks).

A standard deck has 4 suits and 13 ranks. Return the five cards that form the highest straight flush, or empty if none exists.

### Example
```
Input 1: [S1R2, S1R0, S1R1, S0R1, S1R3, S0R7, S1R4]
Output 1: [S1R0, S1R1, S1R2, S1R3, S1R4]
Explanation: Suit 1 has ranks 0,1,2,3,4 forming a straight flush

Input 2: [S0R7, S2R0, S0R1, S2R1, S2R2, S2R3, S2R5, S2R4]
Output 2: [S2R1, S2R2, S2R3, S2R4, S2R5]
Explanation: Suit 2 has ranks 1,2,3,4,5 forming the highest straight flush
```

### C++ Solution
```cpp
struct Card {
    int suit;  // 0-3
    int rank;  // 0-12

    Card(int s, int r) : suit(s), rank(r) {}
};

class Solution {
public:
    vector<Card> findHighestStraightFlush(vector<Card>& cards) {
        const int MAX_SUIT = 4;
        const int MAX_RANK = 13;
        const int MATCH_LENGTH = 5;

        // Group cards by suit
        vector<vector<int>> suitRanks(MAX_SUIT);

        for (const Card& card : cards) {
            suitRanks[card.suit].push_back(card.rank);
        }

        vector<Card> result;
        int highestStartRank = -1;
        int bestSuit = -1;

        // Check each suit for straight flushes
        for (int suit = 0; suit < MAX_SUIT; suit++) {
            if (suitRanks[suit].size() < MATCH_LENGTH) continue;

            // Sort ranks for this suit
            vector<int>& ranks = suitRanks[suit];
            sort(ranks.begin(), ranks.end());

            // Find consecutive sequences
            for (int i = 0; i <= (int)ranks.size() - MATCH_LENGTH; i++) {
                bool isConsecutive = true;

                for (int j = 0; j < MATCH_LENGTH - 1; j++) {
                    if (ranks[i + j + 1] != ranks[i + j] + 1) {
                        isConsecutive = false;
                        break;
                    }
                }

                if (isConsecutive && ranks[i] > highestStartRank) {
                    highestStartRank = ranks[i];
                    bestSuit = suit;
                }
            }
        }

        // Build result if found
        if (highestStartRank != -1) {
            for (int r = highestStartRank; r < highestStartRank + MATCH_LENGTH; r++) {
                result.push_back(Card(bestSuit, r));
            }
        }

        return result;
    }
};
```

**Time Complexity:** O(N log N) where N is number of cards
**Space Complexity:** O(N)

## Question 2: Check Palindrome by Splitting and Concatenating

**Difficulty:** Medium

### Problem Statement
Given two strings A and B of equal length N, check if you can split both strings at any index i (0 ≤ i ≤ N-1) and concatenate parts to form a palindrome.

You can form: `A[0:i] + B[i:N]` or `B[0:i] + A[i:N]`

Return true if any such split creates a palindrome.

### Example
```
Input: A = "x", B = "y"
Output: true
Explanation: Split at index 0: "" + "y" = "y" (palindrome)

Input: A = "xbdef", B = "xecab"
Output: false
Explanation: No split position creates a palindrome

Input: A = "xyzdef", B = "rstzyx"
Output: true
Explanation: A[0:3] + B[3:6] = "xyz" + "zyx" = "xyzzyx" (palindrome)
```

### C++ Solution
```cpp
class Solution {
public:
    bool checkPalindromeConcatenation(string a, string b) {
        int n = a.length();

        for (int i = 0; i <= n; i++) {
            // Check A[0:i] + B[i:n]
            string concat1 = a.substr(0, i) + b.substr(i);
            if (isPalindrome(concat1)) return true;

            // Check B[0:i] + A[i:n]
            string concat2 = b.substr(0, i) + a.substr(i);
            if (isPalindrome(concat2)) return true;
        }

        return false;
    }

private:
    bool isPalindrome(const string& s) {
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s[left] != s[right]) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

**Time Complexity:** O(N²) - N splits, each palindrome check is O(N)
**Space Complexity:** O(N) for substring creation

**Optimization:** Two-pointer approach without creating substrings
```cpp
class Solution {
public:
    bool checkPalindromeConcatenation(string a, string b) {
        int n = a.length();

        // Try all split positions
        for (int i = 0; i <= n; i++) {
            if (canFormPalindrome(a, b, i) || canFormPalindrome(b, a, i)) {
                return true;
            }
        }
        return false;
    }

private:
    bool canFormPalindrome(const string& a, const string& b, int split) {
        int left = 0, right = a.length() - 1;

        while (left < right) {
            char leftChar = (left < split) ? a[left] : b[left];
            char rightChar = (right < split) ? a[right] : b[right];

            if (leftChar != rightChar) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

**Optimized Time Complexity:** O(N²)
**Optimized Space Complexity:** O(1)

## Question 3: Remove A's and Double B's In-Place

**Difficulty:** Hard

### Problem Statement
Given a partially filled array containing only 'A's and 'B's, remove all 'A's and double all 'B's in-place. If it's not possible (not enough space), return the original array.

The array has extra space at the end to accommodate doubled B's.

### Example
```
Input: ['A', 'B', 'B', 'A', '_', '_', '_', '_']
Output: ['B', 'B', 'B', 'B', '_', '_', '_', '_']
Explanation: Removed 2 A's, doubled 2 B's

Input: ['A', 'B', 'A', 'B', '_']
Output: ['A', 'B', 'A', 'B', '_']
Explanation: Not enough space to double both B's, return original

Input: ['B', 'B', 'B', '_', '_', '_']
Output: ['B', 'B', 'B', 'B', 'B', 'B']
```

### C++ Solution
```cpp
class Solution {
public:
    void removeAandDoubleB(vector<char>& arr) {
        int n = arr.size();

        // Count A's and B's
        int countA = 0, countB = 0;
        int validLength = 0;

        for (int i = 0; i < n && arr[i] != '_'; i++) {
            if (arr[i] == 'A') countA++;
            else if (arr[i] == 'B') countB++;
            validLength++;
        }

        // Check if we have enough space
        int finalLength = countB * 2; // Remove A's, double B's
        if (finalLength > n) {
            return; // Not possible, array remains unchanged
        }

        // Two pointers: read from end, write from final position
        int read = validLength - 1;
        int write = finalLength - 1;

        while (read >= 0 && write >= 0) {
            if (arr[read] == 'B') {
                arr[write--] = 'B';
                arr[write--] = 'B';
            }
            // Skip A's (don't write them)
            read--;
        }

        // Fill remaining with underscores
        for (int i = finalLength; i < n; i++) {
            arr[i] = '_';
        }
    }
};
```

**Time Complexity:** O(N)
**Space Complexity:** O(1)

## Question 4: Sliding Window Maximum Stock Prices

**Difficulty:** Medium

### Problem Statement
Given an array of stock prices and a window size `second`, find the maximum stock price in each sliding window of size `second`.

### Example
```
Input: prices = [17,20,19,4,9,10,12,24], second = 3
Output: [17,20,20,20,19,10,12,24]

Explanation:
Window [17] -> max = 17
Window [17,20] -> max = 20
Window [17,20,19] -> max = 20
Window [20,19,4] -> max = 20
Window [19,4,9] -> max = 19
Window [4,9,10] -> max = 10
Window [9,10,12] -> max = 12
Window [10,12,24] -> max = 24
```

### C++ Solution
```cpp
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& prices, int k) {
        vector<int> result;
        deque<int> dq; // stores indices

        for (int i = 0; i < prices.size(); i++) {
            // Remove elements outside current window
            while (!dq.empty() && dq.front() <= i - k) {
                dq.pop_front();
            }

            // Remove smaller elements (they won't be max)
            while (!dq.empty() && prices[dq.back()] < prices[i]) {
                dq.pop_back();
            }

            dq.push_back(i);

            // The front is always the maximum in current window
            result.push_back(prices[dq.front()]);
        }

        return result;
    }
};
```

**Time Complexity:** O(N) - each element added/removed once
**Space Complexity:** O(K) for deque

## Question 5: Count Smaller Elements in Stream

**Difficulty:** Hard

### Problem Statement
Design a data structure that supports adding integers from a stream and querying the number of elements smaller than a given value.

Implement:
- `void add(int num)` - Add number to stream
- `int countSmaller(int num)` - Return count of numbers < num in stream

### Example
```
add(5)
add(2)
add(8)
countSmaller(5) -> 1 (only 2 is smaller)
add(3)
countSmaller(5) -> 2 (2 and 3 are smaller)
countSmaller(10) -> 4 (all elements)
```

### C++ Solution (Using Balanced BST)
```cpp
struct TreeNode {
    int val;
    int count;      // count of nodes in left subtree
    TreeNode *left, *right;

    TreeNode(int v) : val(v), count(0), left(nullptr), right(nullptr) {}
};

class StreamCounter {
private:
    TreeNode* root;

    TreeNode* insert(TreeNode* node, int val, int& smaller) {
        if (!node) {
            return new TreeNode(val);
        }

        if (val <= node->val) {
            node->count++;
            node->left = insert(node->left, val, smaller);
        } else {
            smaller += node->count + 1; // all left + current node
            node->right = insert(node->right, val, smaller);
        }

        return node;
    }

    int countSmaller(TreeNode* node, int val) {
        if (!node) return 0;

        if (val <= node->val) {
            return countSmaller(node->left, val);
        } else {
            return node->count + 1 + countSmaller(node->right, val);
        }
    }

public:
    StreamCounter() : root(nullptr) {}

    void add(int num) {
        int smaller = 0;
        root = insert(root, num, smaller);
    }

    int getSmallerCount(int num) {
        return countSmaller(root, num);
    }
};
```

**Time Complexity:**
- add: O(log N) average, O(N) worst case
- countSmaller: O(log N) average, O(N) worst case

**Space Complexity:** O(N)

### Alternative Solution (Using multiset - simpler)
```cpp
class StreamCounter {
private:
    multiset<int> nums;

public:
    void add(int num) {
        nums.insert(num);
    }

    int getSmallerCount(int num) {
        return distance(nums.begin(), nums.lower_bound(num));
    }
};
```

**Time Complexity:**
- add: O(log N)
- countSmaller: O(log N)

**Space Complexity:** O(N)

## Question 6: Graph Connectivity Timing

**Difficulty:** Hard

### Problem Statement
Given a directed graph with connections that are made at different times, find the earliest time when all nodes become reachable from all other nodes (strongly connected).

Connections are given as `[from, to, time]`.

### Example
```
Input: n = 4, connections = [[0,1,1], [1,2,2], [2,0,3], [1,3,4], [3,1,5]]
Output: 5
Explanation: At time 5, all nodes can reach all other nodes

Time 1: 0->1
Time 2: 0->1->2
Time 3: 0->1->2->0 (cycle formed)
Time 4: 0->1->2->0, 1->3
Time 5: All nodes strongly connected (1->3->1 cycle completes)
```

### C++ Solution
```cpp
class Solution {
public:
    int earliestFullConnection(int n, vector<vector<int>>& connections) {
        // Sort connections by time
        sort(connections.begin(), connections.end(),
             [](const auto& a, const auto& b) { return a[2] < b[2]; });

        int maxTime = 0;

        for (const auto& conn : connections) {
            maxTime = max(maxTime, conn[2]);
        }

        // Binary search on time
        int left = 0, right = maxTime;
        int result = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (isStronglyConnected(n, connections, mid)) {
                result = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return result;
    }

private:
    bool isStronglyConnected(int n, vector<vector<int>>& connections, int time) {
        // Build graph with edges available at given time
        vector<vector<int>> graph(n);

        for (const auto& conn : connections) {
            if (conn[2] <= time) {
                graph[conn[0]].push_back(conn[1]);
            }
        }

        // Check if every node can reach every other node
        for (int start = 0; start < n; start++) {
            vector<bool> visited(n, false);
            dfs(graph, start, visited);

            // Check if all nodes reachable from start
            for (bool v : visited) {
                if (!v) return false;
            }
        }

        return true;
    }

    void dfs(vector<vector<int>>& graph, int node, vector<bool>& visited) {
        visited[node] = true;
        for (int neighbor : graph[node]) {
            if (!visited[neighbor]) {
                dfs(graph, neighbor, visited);
            }
        }
    }
};
```

**Time Complexity:** O(E log T × N × (N + E)) where T is max time
**Space Complexity:** O(N + E)

## Question 7: Remove Leaf/Subtree from N-ary Tree Array

**Difficulty:** Medium

### Problem Statement
Given an N-ary tree represented as an array where each element contains parent information, return the modified array when a leaf node (or subtree) is removed.

Array format: `[node_value, parent_index]`

### Example
```
Input: nodes = [[1,-1], [2,0], [3,0], [4,1], [5,1]], removeNode = 4
Output: [[1,-1], [2,0], [3,0], [5,1]]
Explanation: Node 4 (leaf) is removed

Input: nodes = [[1,-1], [2,0], [3,0], [4,1], [5,1]], removeNode = 1
Output: [[1,-1], [2,0], [3,0]]
Explanation: Node 1 and its subtree (4,5) are removed
```

### C++ Solution
```cpp
class Solution {
public:
    vector<vector<int>> removeNode(vector<vector<int>>& nodes, int removeIdx) {
        int n = nodes.size();

        // Build parent-child relationship
        vector<vector<int>> children(n);
        for (int i = 0; i < n; i++) {
            int parent = nodes[i][1];
            if (parent != -1) {
                children[parent].push_back(i);
            }
        }

        // Find all nodes in subtree to remove
        set<int> toRemove;
        findSubtree(removeIdx, children, toRemove);

        // Build result excluding removed nodes
        vector<vector<int>> result;
        unordered_map<int, int> oldToNew; // map old index to new index

        int newIdx = 0;
        for (int i = 0; i < n; i++) {
            if (toRemove.find(i) == toRemove.end()) {
                oldToNew[i] = newIdx++;
                result.push_back(nodes[i]);
            }
        }

        // Update parent indices
        for (auto& node : result) {
            if (node[1] != -1) {
                node[1] = oldToNew[node[1]];
            }
        }

        return result;
    }

private:
    void findSubtree(int node, vector<vector<int>>& children, set<int>& toRemove) {
        toRemove.insert(node);
        for (int child : children[node]) {
            findSubtree(child, children, toRemove);
        }
    }
};
```

**Time Complexity:** O(N) where N is number of nodes
**Space Complexity:** O(N)

## Interview Tips Based on These Experiences

### What Went Well:
- ✅ Providing optimal solutions with correct complexity analysis
- ✅ Using appropriate data structures (BST, deque, hash maps)
- ✅ Clear communication of approach before coding

### Common Pitfalls:
- ❌ **Slow coding speed** - Practice implementing solutions quickly
- ❌ **Not completing follow-ups** - Always leave time for extensions
- ❌ **Over-reliance on library functions** - Be ready to implement from scratch

### Key Takeaways:
1. **Speed matters** - Balance between optimality and implementation speed
2. **Follow-ups are critical** - Initial solution is just the start
3. **Understand your tools** - Know when to use built-in vs custom implementations
4. **Test edge cases** - Empty inputs, single elements, all same values
5. **Communicate continuously** - Explain your thought process
